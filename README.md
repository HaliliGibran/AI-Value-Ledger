## 评级规则

| 等级 | 判断标准 |
| --- | --- |
| **甲** | 满足其一即可：① 高性能模型免费，正常使用不排队、无明显限流；② 免费无限额度，正常使用不受严重速度或任务限制；③ 单期免费巨额额度（参考至少 1 亿 Token），且没有明显限速或排队。每天只给极少次数，即使不排队，也不算甲等。 |
| **乙** | 免费模型存在一定排队、限速或周期限制，但仍可完成较大型任务；或赠送大量免费额度，但使用约束明显。 |
| **丙** | 有实际备用价值的免费额度（通常参考至少 1,000 万 Token），但总量、期限、分模型额度或速度限制明显。 |
| **丁** | 小额试用、严重排队限流、优惠有限，或需较高额付费才能获得实际权益；原则上不入活动表。 |

**分级与是否支持 API 无关；地区、新用户、学生或其他身份要求只标注资格，不直接降级。** 不同模型 Token、积分与金额不能任意换算。跨模型的赠送额度不得当作某单一模型的额度。

## 更新规则

- 只收录**已核验且当前仍有效**、达到甲乙丙标准的活动；截至日期或适用地区不明时直接在表格标明，不推测。
- 每行保留活动权益、限制、资格、期限、官方来源和核验日期。未经确认的“无限”“不排队”、过期活动和历史传闻不写成有效事实。
- 每天北京时间 12:00 计划更新。仅限本仓库上述四个文件，不新建子目录，不公开个人账户信息、使用余额或密钥。
- 日常报告只说更新结果与新增甲等数量；**仅在有依据的 Codex Business 重置提醒时主动通知**。下一次个人周期重置若没有真实用量数据，不得猜测具体日期。
