## 甲乙丙丁评级

| 等级 | 判定 |
| --- | --- |
| **甲** | 免费高性能模型正常使用不排队、无明显限流；或免费无限额度且足以完成正常大型任务；或单期极大赠额（文本参考至少 1 亿 Token）且无明显限流排队。仅有极少免费次数不算甲。 |
| **乙** | 免费权益足以支撑较大型任务，但有一定排队、限流、周期或额度限制；或免费赠额很高但限制明显。 |
| **丙** | 免费权益具备实际备用价值（文本可参考约 1000 万 Token），但次数、速度、时长、分模型配额或使用期限受限。 |
| **丁** | 小额试用、严重限流排队或低价值促销，原则上不收录。 |

分级与是否支持 API 无关。地区、新用户、学生资格只标注条件，不直接降级。图像、视频、3D、音乐和语音按可生成作品数、成品时长、质量、速度及限制评价，**不能拿文本 Token 门槛机械套用**；不同模型 Token、Credits、金额不可随意换算。

## 截止日期和更新方式

- 新活动必须填写**活动截止时间（北京时间）**，优先使用官方明确的最后领取时间（含日期、时刻及原始时区）；只有日期没有时刻时如实标为“具体时刻未公布”，绝不擅自补成 23:59。**活动领取截止**和**领取后权益有效期**分列，不能混为一谈。
- 官方没有公布截止时间，则明确填“官方未公布”，不能臆造日期；这种项目每 7 天抽查一次或发现撤销信息时立即处理。官方明确长期有效则填“长期有效（官方说明）”，每月检查政策变化。
- **截止时间未到的已收录活动，不再进行每日逐条复核**；只做日期判断，除非厂商主动发布撤销、限额调整或规则变化。
- 已过截止时间：先查官方延期、续批或调整公告；**没有可核实延期**就从 AI活动单与 API活动单移除。领取后的额度尚未到期，不代表新用户还能继续领取。
- 新发现的活动可来自官网、公开新闻、社区讨论及 X 帖子。普通用户爆料只作线索；来源是官方认证账号且明确写明权益与期限的 X 原帖，可作为原始证据。核验资格、额度、速度、截至时间后才入表。无法访问 X 原文或未查到可靠信息时不编造。
- 每天北京时间 12:00 更新；每天搜索大型模型及其编码／Agent 产品、独立 Agent、图像、视频、3D／世界、音乐、语音赛道，兼顾中文英文和 X。只打开高价值线索的原文，避免重复获取未到期活动的长页面。
- 只维护根目录四个 Markdown 文件，不新建历史或归档；三个数据文件保持**纯表格**。活动单按甲、乙、丙排序，过期直接移除；同一活动仅计一次新增甲等，API 子表重复不另计。
- 日常任务只简短回复“已更新AI活动单，新增甲等X项。”如有可靠未来 Codex Business 重置，先在同一回复第一句提醒，直到该时刻过去；不另建提醒任务。
