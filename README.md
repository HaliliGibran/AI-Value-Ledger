## 收录和证据标准

1. **Codex 永久例外**：不设置“至少 1,000 万 Token”的价值门槛，任何官方明确的额度、模型倍率、重置/备用重置、5h/weekly 限制、推广或回退均应保留并跟踪；Business Standard/Premium 优先于 Pro/Plus。
2. **非 Codex**：通常收录可实现约 1,000 万普通 LLM Token 量级的真实大额赠送，或能持续完成较大型编程任务的限免/高配额/0x/0 Credits 产品。不同模型的 Token、平台 Credits、美元价值**不能擅自等价换算**。
3. **等级**：A＝官方明确无明显妨碍大型任务的无限使用；B＝极高容量、可持续 0x/近无限但存在正常限流；C＝可观的大额免费或周期配额；D＝高价值但地区、身份、付费或审核门槛明显。等级代表使用约束，不代表来源可信等级。
4. **可复核性**：每条应有稳定 ID、官方链接、首次/最近核验日期、地区与资格、Web/IDE/CLI/API 渠道、额度与刷新周期、活动结束日期/时区（或“未披露”）。优先官方公告、定价与帮助中心。
5. **时效**：活动过期后必须移入 archive；官方声明延长才可以视作续期；历史活动不能因旧网页仍可访问就继续判定有效。
6. **事实界限**：区分**规则已核验**与**个人账号是否到账**；区分官方宣布、正在推送和全部生效。无法公开核验的细节应进入 watchlist，不凭空填写。
7. **公开仓库卫生**：禁止提交个人额度截图、账户 ID、Cookie、Token、密钥、账单、财务/健康或任何其他私密资料。始终只写公开渠道已公布的信息。
